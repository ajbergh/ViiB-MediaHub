# ViiB MediaHub v1.0.0-rc6

Release candidate 6 includes UI, library-performance, Smart Playlist, media-format, and security improvements since RC5. This is a **pre-release** intended for validation before 1.0 general availability.

## Highlights since RC5

- **Modernized desktop experience and large libraries:** Refreshed navigation, player, track lists and Spotify views; virtualized long queues and reduced unnecessary rendering for collections with 10,000+ tracks. ([#122](https://github.com/ajbergh/ViiB-MediaHub/pull/122))
- **Smarter local playlists:** Managed on-device semantic matching, background indexing, offline model reuse, improved playlist/DJ retrieval, and deterministic fallback behavior. First-time model download is approximately 31 MB. ([#124](https://github.com/ajbergh/ViiB-MediaHub/pull/124))
- **Spotify Free/Premium capability handling:** Free accounts retain browsing and metadata features; streaming and downloads are gated behind verified Premium access. Spotify metadata persistence and lifecycle handling were also improved. ([#124](https://github.com/ajbergh/ViiB-MediaHub/pull/124), [#117](https://github.com/ajbergh/ViiB-MediaHub/pull/117))
- **FLAC/M4A browser imports:** Added browser import and metadata support for FLAC and M4A, with clear unsupported-analysis indicators where full backend analysis is unavailable. ([#120](https://github.com/ajbergh/ViiB-MediaHub/pull/120), [#121](https://github.com/ajbergh/ViiB-MediaHub/pull/121))
- **Security and credentials:** Hardened loopback Host/Origin/CORS and SSE policies; introduced versioned credential encryption and migration that survives executable relocation. Some unrecoverable legacy secrets may require reconnecting the integration. ([#118](https://github.com/ajbergh/ViiB-MediaHub/pull/118), [#119](https://github.com/ajbergh/ViiB-MediaHub/pull/119))
- **Scan and analysis robustness:** Improved parser resource handling, job scheduling, and metadata extraction; new compact three-band waveform storage reduces the size of those artifacts without automatically shrinking an existing database file. ([#123](https://github.com/ajbergh/ViiB-MediaHub/pull/123))

## Desktop installers

- **Windows 10/11 x64:** `ViiB-MediaHub-1.0.0-rc6-windows-x64-setup.exe`
- **macOS Apple Silicon:** `ViiB-MediaHub-1.0.0-rc6-macos-arm64.dmg`
- **macOS Intel:** `ViiB-MediaHub-1.0.0-rc6-macos-x64.dmg`
- **Ubuntu/Debian x64:** `ViiB-MediaHub-1.0.0-rc6-linux-amd64.deb`
- **Linux x64 (portable):** `ViiB-MediaHub-1.0.0-rc6-linux-amd64.tar.gz`

## Web/browser builds

Download the `ViiB-MediaHub-1.0.0-rc6-web-<platform>.zip` archive for Windows x64/ARM64, macOS x64/ARM64, or Linux amd64/arm64. Extract and run the bundled server; the frontend is included and opens in a local browser. On Linux without Ayatana AppIndicator, use `-no-tray`.

`SHA256SUMS.txt` lists SHA-256 hashes for all distributed builds.

## Release-candidate notes

- macOS DMGs are ad-hoc signed but not Apple notarized; Gatekeeper may require **Open Anyway**.
- Windows application/installer Authenticode signing depends on configured repository signing credentials; SmartScreen may warn if absent.
- Linux desktop builds use WebKitGTK 4.1; other distributions require compatible GTK/WebKitGTK runtime dependencies.
- This build is a release candidate. Back up your library data/settings before upgrading and report regressions via [GitHub Issues](https://github.com/ajbergh/ViiB-MediaHub/issues).
