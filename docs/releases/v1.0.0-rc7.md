# ViiB MediaHub v1.0.0-rc7

Release candidate 7 packages changes merged to `main` since RC6. This is a **pre-release** for testing before the 1.0 general-availability release.

## What's new since RC6

- **Spotify BPM and harmonic-key accuracy:** Prefer Spotify Web Player audio attributes V2 when available, including provenance-aware caching and strict decoding. Legacy values remain available as fallback. Added diagnostic utilities to compare metadata and probe Free-account audio capabilities. ([#125](https://github.com/ajbergh/ViiB-MediaHub/pull/125))
- **DJ Mode v2 workstation refinements:** Updated dual-deck layout, aligned stacked and vertical waveforms, clearer performance/library controls, refreshed mixer controls, larger loop controls, and deck-colored hot cues. ([#126](https://github.com/ajbergh/ViiB-MediaHub/pull/126))
- **Waveform and mixing performance:** Reduced waveform rendering overhead with GPU three-band support, cached Canvas tiles, peak pyramids, worker/fallback rendering, and shared meter scheduling. Improved crossfader curve behavior, sync prerequisites, and phase alignment with reviewed manual grids. ([#126](https://github.com/ajbergh/ViiB-MediaHub/pull/126))
- **Milkdrop visualizer:** Enhanced the now-playing Milkdrop visualization experience and added preset-management support with associated automated tests. ([commit](https://github.com/ajbergh/ViiB-MediaHub/commit/d70ca95db02e181aff7cf719e6ee146e087766e7))

See the [full RC6 → RC7 comparison](https://github.com/ajbergh/ViiB-MediaHub/compare/v1.0.0-rc6...v1.0.0-rc7).

## Web/browser builds

Download `ViiB-MediaHub-1.0.0-rc7-web-<platform>.zip` for Windows x64/ARM64, macOS x64/ARM64, or Linux amd64/arm64. Extract it and run the included local server to open the bundled frontend in your browser. On Linux without Ayatana AppIndicator, run with `-no-tray`.

The `SHA256SUMS.txt` asset records SHA-256 hashes for the distributed packages.

## Release-candidate limitations and validation

- macOS DMGs use ad-hoc signing and are not Apple-notarized; Gatekeeper may require **Open Anyway**.
- Windows Authenticode signing depends on configured repository credentials; unsigned builds may trigger SmartScreen warnings.
- Linux desktop builds require compatible GTK/WebKitGTK 4.1 dependencies.
- Spotify V2 audio metadata relies on a private Web Player protocol that may change. Spotify Free playback/download support is **not** enabled by these changes.
- Real-device DJ listening checks and native macOS/WKWebView verification remain useful regression tests; phase sync requires reviewed, locked manual grids.
- Back up your local library data before upgrading and report regressions in [GitHub Issues](https://github.com/ajbergh/ViiB-MediaHub/issues).
