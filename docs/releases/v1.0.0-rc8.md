# ViiB MediaHub v1.0.0-rc8

Release candidate 8 incorporates the work on `main` since RC7 and updates the Go build toolchain to **Go 1.26.10** to address [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) in `crypto/x509`. This is a **prerelease** for validation, not a declaration of production readiness.

## Changes since RC7

- **MixTrack Go MIDI and stem recovery:** Added controller handshake/feedback, bank-aware hot cues, loop/sampler/stem pad actions and library navigation. Improved stem startup/seek buffering, stale-operation handling and recovery from missing audio frames. ([#128](https://github.com/ajbergh/ViiB-MediaHub/pull/128))
- **Experimental controller mappings:** Added input-only presets for Numark DJ2GO, Behringer CMD Micro, Hercules DJControl Compact and Pioneer DDJ-400, with more stable mapping IDs and isolated per-device mappings. Hardware/firmware qualification is still required. ([#129](https://github.com/ajbergh/ViiB-MediaHub/pull/129))
- **Single-device four-channel DJ output:** Added routing for main audio on channels 1–2 and headphones on channels 3–4 where a compatible four-channel device is exposed; includes fallback/recovery handling, cue/master blending and routing tests. Physical output separation still requires validation. ([#130](https://github.com/ajbergh/ViiB-MediaHub/pull/130))
- **Release integrity and governance:** Added production-signing safeguards for stable releases, exact-asset checksum checks, dependency inventories and build-provenance verification; broadened strict typing, browser and recovery tests, accessibility and diagnostic safeguards, and documented governance policies. ([#153](https://github.com/ajbergh/ViiB-MediaHub/pull/153), [#154](https://github.com/ajbergh/ViiB-MediaHub/pull/154))
- **Security maintenance:** Moved CI and release builds to Go 1.26.10, which includes the `crypto/x509` fix for [CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809).

## Web/browser packages

Choose `ViiB-MediaHub-1.0.0-rc8-web-<platform>.zip` for Windows x64/ARM64, macOS x64/ARM64, or Linux amd64/arm64. Each archive includes an executable that serves the bundled frontend locally in a browser. On Linux without Ayatana AppIndicator support, use `-no-tray`.

## Verification and constraints

- `SHA256SUMS.txt` covers all platform binaries and dependency inventory payloads.
- `npm-sbom.cdx.json` and `go-modules.json` provide npm and Go dependency inventories. These do not establish native-library completeness or license compliance.
- The release pipeline attests/verifies payload provenance before publication; see [provenance documentation](https://github.com/ajbergh/ViiB-MediaHub/blob/main/docs/release-provenance.md).
- macOS DMGs are ad-hoc signed, not notarized; Gatekeeper may require **Open Anyway**. Windows signing depends on configured credentials.
- Experimental MIDI profiles and four-channel routing require real-device validation. Stable 1.0 release qualification is not implied by RC8 packaging.
- Back up your local library data before upgrading. Report regressions in [Issues](https://github.com/ajbergh/ViiB-MediaHub/issues).
