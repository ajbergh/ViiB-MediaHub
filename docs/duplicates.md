# Duplicates

![Duplicates page](../assets/screenshots/duplicates.png)

The Duplicates page reviews groups of likely duplicate catalog tracks. It is a ViiB catalog-management surface and works with local and synchronized Plex entries through the normal catalog identity.

## Reviewing groups

Open **Duplicates** from the sidebar. Each group lists the matching songs and exposes the available review controls. Duplicate detection does not delete source audio or modify Plex-hosted media.

## Ignoring a match

Use the ignore control to mark a song as intentionally retained. Ignored entries remain in the ViiB catalog and can be reviewed again from the ignored-items view.

After changing duplicate state, ViiB refreshes the catalog so Songs, search, playlists, and other source-transparent views reflect the current result.
