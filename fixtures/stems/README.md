# Compressed codec interoperability fixtures


`package-v1-{mp3,ogg}-{mono,stereo}-{ffmpeg,soundfile}.viibstems` contain
only the selected codec, with `requiredFeatures: ["compressed-stems-v1"]`.
They were generated by `scripts/generate_codec_fixtures.py` using FFmpeg
2025-01-30-git-1911a6ec26 and SoundFile 0.14.0 (libsndfile 1.2.2).
Both repositories use identical bytes. Each file has 44,117 gapless frames:
mono at 22,050 Hz or stereo at 44,100 Hz. Reference source WAVs live separately
in `source/`. Impulses at frames 512, 11,025 and 40,000 test absolute alignment,
seek accuracy, and end padding; they make no separation-quality claim.

`codecs/long-seek.mp3` and `.ogg` contain 700,003 stereo frames at 44,100 Hz, with impulses at frames 512 and 650,000. These FFmpeg fixtures exercise seeking beyond the MP3 warm-up window without shipping a large reference WAV.
